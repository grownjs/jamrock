# Build a Game: Lucky Streak

A little server-side game is a useful way to see Jamrock's streaming model in motion. We will stream a meteor shower of numbers, keep one standing guess on the server, and celebrate only the matches the server secretly marks as lucky.

> [!IMPORTANT] > The lucky flag is server-only. A number that is lucky but does not match your guess is rendered exactly like every ordinary meteor.

1. Stream numbers into a list

An async generator yields a new number on an interval. Put it inside a fragment with mode="prepend", and each new result lands at the top of the list. The limit keeps the stream bounded.

```html {#each numbers as number}
  • Meteor: {number}
    • {/each}     ``` The generator itself just yields as fast as it's asked to — it's the fragment's `interval` that paces how often a new value is pulled and pushed to the browser.
