**Jamrock** is a framework for the server-side, 1. It compiles your `.html` files into something that can be called server-components. 2. The server will execute them against the request and responds with HTML or JSON as needed. 3. The browser will take the HTML as is — but if JavaScript is available the framework will get JSON to patch the DOM with the changes, resulting on smoother updates. Use the script below to download the package and uncompress it locally at your `$HOME`. ``` curl -L get.jamrock.dev | bash jamrock init my-app ... cd my-app npm install bin/node dev ``` You should get something like this: ``` ■ Jamrock v0.0.0 (node {process.version}) Processing ./pages to ./build Listening on http://localhost:8080 ``` Open that URL in your browser and explore!
